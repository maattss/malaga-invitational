# Spillerbilder

Legg inn ekte bilder her for å erstatte de genererte avatarene.

- Filnavnet **må** matche spillerens `seed` i `src/data/trip.ts`.
- Støttede format: `.jpg`, `.jpeg`, `.png`, `.webp`.
- Helst kvadratiske bilder (f.eks. 400×400). De vises sirkulært.
